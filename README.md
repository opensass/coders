## 📜 Intro

A highly customizable, accessible inline code and code-block component for WASM frameworks: Yew, Dioxus, and Leptos. Supports multiple colors, variants, sizes, copy-to-clipboard, and composable sub-components, all WCAG compliant.

## 🤔 Why Code RS?

1. **🎨 Fully Customizable**: Control every attribute, class, style, color, variant, size, ARIA labels, and more.
1. **📋 Copy to Clipboard**: Built-in copy button with a configurable confirmation label and reset timeout.
1. **🧩 Composable**: Compose `Header`, `Title`, `CopyTrigger`, `Content`, and `LanguageBadge` independently.
1. **♿ Accessible by Default**: `role="region"`, `aria-label`, `aria-live` and `tabindex` wired up automatically.
1. **🔧 Framework Agnostic**: Same API semantics across Yew, Dioxus, and Leptos.
